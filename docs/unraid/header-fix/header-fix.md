# WebGUI Header Link Fix

## Purpose

Have you ever clicked the "Unraid" link at the top of the WebGUI expecting to return to the start page, only to find yourself whisked away to unraid.net?

This plugin fixes that. Clicking the "Unraid" link will now take you back to the start page of your WebGUI, as it should.

## Installation

The plugin can be installed by using the following URL in the "Install Plugin" page of the Unraid WebGUI:

```text
https://raw.githubusercontent.com/dkaser/unraid-header-fix/main/plugin/header-fix.plg
```
